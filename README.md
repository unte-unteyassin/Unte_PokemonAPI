# Pokémon REST API

A simple REST API built with **Python Flask** and **SQLite** for managing handcrafted Pokémon data.

This project demonstrates the basic **CRUD operations**:

- Create Pokémon
- Read Pokémon
- Update Pokémon
- Delete Pokémon

---

## Technologies Used

- Python
- Flask
- SQLite
- REST API
- curl / Postman
- Git & GitHub

## Data

The API uses **15 handcrafted Pokémon records**.

Each Pokémon contains:

- `id`
- `name`
- `type`
- `hp`
- `attack`
- `defense`

The data was manually created for this project and was **not pulled from a free Pokémon API**.

# API Endpoints

## 1. GET `/pokemon`

Returns all Pokémon in the database.

### Request

```bash
curl.exe -i http://127.0.0.1:5000/pokemon
```

### Response

**Status: `200 OK`**

```json
[
  {
    "id": 1,
    "name": "Bulbasaur",
    "type": "Grass/Poison",
    "hp": 52,
    "attack": 61,
    "defense": 55
  }
]
```

The actual response contains all Pokémon currently stored in the database.

---

## 2. GET `/pokemon/<id>`

Returns one Pokémon using its ID.

### Request

```bash
curl.exe -i http://127.0.0.1:5000/pokemon/1
```

### Response

**Status: `200 OK`**

```json
{
  "id": 1,
  "name": "Bulbasaur",
  "type": "Grass/Poison",
  "hp": 52,
  "attack": 61,
  "defense": 55
}
```

### Pokémon Not Found

If the specified ID does not exist:

```bash
curl.exe -i http://127.0.0.1:5000/pokemon/999
```

**Status: `404 Not Found`**

```json
{
  "error": "Pokemon not found"
}
```

---

## 3. POST `/pokemon`

Creates a new Pokémon.

### Request

```bash
curl.exe -i -X POST http://127.0.0.1:5000/pokemon -H "Content-Type: application/json" --data-binary "@post.json"
```

Example `post.json`:

```json
{
  "name": "Mimikyu",
  "type": "Ghost/Fairy",
  "hp": 55,
  "attack": 90,
  "defense": 80
}
```

### Response

**Status: `201 Created`**

```json
{
  "id": 16,
  "name": "Mimikyu",
  "type": "Ghost/Fairy",
  "hp": 55,
  "attack": 90,
  "defense": 80
}
```

The ID is automatically generated by SQLite.

---

## 4. PUT `/pokemon/<id>`

Updates an existing Pokémon.

### Request

```bash
curl.exe -i -X PUT http://127.0.0.1:5000/pokemon/16 -H "Content-Type: application/json" --data-binary "@put.json"
```

Example `put.json`:

```json
{
  "name": "Mimikyu",
  "type": "Ghost/Fairy",
  "hp": 55,
  "attack": 100,
  "defense": 90
}
```

### Response

**Status: `200 OK`**

```json
{
  "id": 16,
  "name": "Mimikyu",
  "type": "Ghost/Fairy",
  "hp": 55,
  "attack": 100,
  "defense": 90
}
```

---

## 5. DELETE `/pokemon/<id>`

Deletes a Pokémon using its ID.

### Request

```bash
curl.exe -i -X DELETE http://127.0.0.1:5000/pokemon/16
```

### Response

**Status: `200 OK`**

```json
{
  "message": "Pokemon with id 16 deleted successfully"
}
```

If the Pokémon does not exist:

**Status: `404 Not Found`**

```json
{
  "error": "Pokemon not found"
}
```

# Validation

The API performs basic validation when creating or updating Pokémon.

The following fields are required:

```text
name
type
hp
attack
defense
```

If a required field is missing, the API returns:

**Status: `400 Bad Request`**

Example:

```json
{
  "error": "Missing required field: type"
}
```

The numeric fields (`hp`, `attack`, and `defense`) must also be integers and cannot be negative.

---

# HTTP Status Codes

| Status Code | Meaning |
|---|---|
| `200 OK` | Successful GET, PUT, or DELETE request |
| `201 Created` | Pokémon successfully created |
| `400 Bad Request` | Invalid or missing request data |
| `404 Not Found` | Pokémon with the specified ID does not exist |
